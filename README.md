# Sistema de Gerenciamento de Lista de Números

Projeto em Python para manipulação de números inteiros via terminal.  
O sistema permite inserir, analisar, organizar e salvar dados em arquivo, simulando operações comuns de processamento de listas.

## Funcionalidades

- Inserir números inteiros (0 encerra a entrada)
- Remover número da lista
- Procurar número na lista
- Ordenar números (crescente ou decrescente)
- Gerar relatório com:
  - Lista completa
  - Soma dos valores
  - Média
  - Maior número
  - Menor número
  - Números pares
  - Números ímpares
  - Quantidade total
- Limpar a lista
- Salvar dados em arquivo `.txt`
- Carregar dados de arquivo `.txt`

## Conceitos aplicados

- Estruturas de repetição (`while`, `for`)
- Tratamento de erros com `try/except`
- Funções e organização de código
- Manipulação de listas
- Condicionais
- Leitura e escrita em arquivos
- Retorno múltiplo de funções

## Como executar

1. Certifique-se de ter Python instalado.
2. Execute o arquivo principal:
python lista_numeros.py

## Objetivo do projeto:

Praticar lógica de programação, manipulação de dados em listas e estruturação de programas em Python, aproximando o aprendizado de situações reais de desenvolvimento.
